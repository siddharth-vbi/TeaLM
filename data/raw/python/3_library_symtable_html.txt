symtable â Access to the compilerâs symbol tablesÂ¶
Source code: Lib/symtable.py
Symbol tables are generated by the compiler from AST just before bytecode is
generated.  The symbol table is responsible for calculating the scope of every
identifier in the code.  symtable provides an interface to examine these
tables.
Generating Symbol TablesÂ¶
- symtable.symtable(code, filename, compile_type)Â¶
- Return the toplevel SymbolTable for the Python source code.
filename is the name of the file containing the code.  compile_type is
like the mode argument tocompile() .

- class symtable.SymbolTableTypeÂ¶
- An enumeration indicating the type of a SymbolTable object.
  - MODULE = "module"Â¶
  - Used for the symbol table of a module.
 
  - FUNCTION = "function"Â¶
  - Used for the symbol table of a function.
 
  - CLASS = "class"Â¶
  - Used for the symbol table of a class.
 The following members refer to different flavors of annotation scopes. 
  - ANNOTATION = "annotation"Â¶
  - Used for annotations if from __future__ import annotations is active.
 
  - TYPE_PARAMETERS = "type parameters"Â¶
  - Used for the symbol table of generic functions or generic classes.
 
  - TYPE_VARIABLE = "type variable"Â¶
  - Used for the symbol table of the bound, the constraint tuple or the default value of a single type variable in the formal sense, i.e., a TypeVar, a TypeVarTuple or a ParamSpec object (the latter two do not support a bound or a constraint tuple).
 Added in version 3.13.

  - get_name()Â¶

- class symtable.ClassÂ¶

  - Return a tuple containing the names of method-like functions declared in the class. Here, the term âmethodâ designates any function defined in the class body via def orasync def .Functions defined in a deeper scope (e.g., in an inner class) are not picked up by get_methods() .For example: >>> import symtable >>> st = symtable.symtable(''' ... def outer(): pass ... ... class A: ... def f(): ... def w(): pass ... ... def g(self): pass ... ... @classmethod ... async def h(cls): pass ... ... global outer ... def outer(self): pass ... ''', 'test', 'exec') >>> class_A = st.get_children()[2] >>> class_A.get_methods() ('f', 'g', 'h') Although A().f() raisesTypeError at runtime,A.f is still
considered as a method-like function.Deprecated since version 3.14, will be removed in version 3.16.

Command-Line UsageÂ¶
Added in version 3.13.
The symtable module can be executed as a script from the command line.
python -m symtable [infile...]
Symbol tables are generated for the specified Python source files and dumped to stdout. If no input file is specified, the content is read from stdin.
