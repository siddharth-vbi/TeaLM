- Return value: New reference. Part of the Stable ABI.Returns the integer n converted to base base as a string. The base argument must be one of 2, 8, 10, or 16. Py_ssize_t PyNumber_AsSsize_t(PyObject *o, PyObject *exc)Â¶
-  Part of the Stable ABI.Returns o converted to a Py_ssize_t value if o can be interpreted as an
integer.  If the call fails, an exception is raised and-1 is returned.If o can be converted to a Python int but the attempt to convert to a Py_ssize_t value would raise anOverflowError , then the
exc argument is the type of exception that will be raised (usuallyIndexError orOverflowError ).  If exc isNULL , then the
exception is cleared and the value is clipped toPY_SSIZE_T_MIN for a negative
integer orPY_SSIZE_T_MAX for a positive integer.
