-  Part of the Stable ABI. Thread safety: Atomic.Set the item at index index in list to item. Return 0 on success.

-  Part of the Stable ABI. Thread safety: Safe for concurrent use on the same object.Set the slice of list between low and high to the contents of itemlist. Analogous to list[low:high] = itemlist . The itemlist may

-  Thread safety: Safe for concurrent use on the same object.Extend list with the contents of iterable.
