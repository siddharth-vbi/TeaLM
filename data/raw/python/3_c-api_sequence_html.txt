PyObject *PySequence_Fast(PyObject *o, const char *m)Â¶
- Return value: New reference. Part of the Stable ABI.Return the sequence or iterable o as an object usable by the other PySequence_Fast* family of functions. If the object is not a sequence or
iterable, raisesTypeError with m as the message text. ReturnsNULL on failure.The PySequence_Fast* functions are thus named because they assume
o is aPyTupleObject or aPyListObject and access
the data fields of o directly.As a CPython implementation detail, if o is already a sequence or list, it will be returned.
